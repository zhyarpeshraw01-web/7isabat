DINAR FLOW — OFFLINE IQD MONEY TRACKER
=====================================

Included months:
- October, November, December 2026
- All 12 months of 2027

Best use on iPhone / iPad:
1. Put the folder on a simple web host (GitHub Pages, Netlify, etc.) if you want Add to Home Screen + service-worker offline mode.
2. Open it once in Safari.
3. Tap Share > Add to Home Screen.
4. After the first load, the hosted version can work offline.

Direct offline use:
- You can also open index.html directly from Files. The app itself has no external dependencies.
- Data is stored in your browser/localStorage on that device/browser.

Important:
- Use Backup regularly. The JSON backup can restore salaries and purchases.
- CSV export opens in Excel / Numbers.
- Clearing Safari website data can delete locally stored app data.

Currency:
- IQD only. USD has been removed entirely.
